# Codon-Translator 🧬➡️💪

A Python + AI tool that translates DNA codons into Amino Acids — Built for Biotechnology & PU-CET.

### What it does 🧪

*   Translates mRNA codons (AUG, UUU etc.) to amino acids
*   Detects Start 🟢 and STOP 🔴 codons
*   Shows Essential vs Non-Essential ⭐
*   Shows charge: Basic 🔵 / Acidic 🔴 / Neutral ⚪
*   Interactive — type any codon and get instant answer

### How to run 🚀

```bash
python translator.py
